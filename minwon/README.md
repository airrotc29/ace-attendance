# 민원 처리 공유 시스템 (`minwon/index.html`)

관리사무소 직원 **누구나** 민원을 올리고, 담당을 정하고, 처리 결과를 사진과 함께 보고하며, 모두가 실시간으로 공유하는 단일 HTML 앱입니다.
(소장님 통화 요구사항 반영: 한 사람이 지시하지 않아도 서로 과업을 주고받고, 카톡처럼 편하되 **통계·검색**이 남도록)

## 주요 기능
- **입장**: 사업소 선택 → 이름 선택 (출퇴근 시스템과 동일 직원 명단, 직급으로 팀 자동 분류: 사무실/시설팀/미화팀/보안팀/주차)
- **민원 접수**: 한 줄 내용·장소·분류·접수경로(전화/방문/순찰 발견…)·사진·담당(미지정/팀/직원/내가 처리)·긴급
- **처리 흐름**: 내가 처리 → 진행 보고(사진) → 완료 처리(완료 사진) → 재발 시 다시 열기. 모든 과정이 타임라인으로 남음
- **채팅**: 전체 단톡방. 작업 안내/수돗물 잠금/점검 등 빠른 문구, 사진 첨부. 접수·담당지정·완료는 자동으로 채팅에 올라오고 눌러서 민원으로 이동
- **통계**: 월별 접수/완료/처리율/평균 처리시간/당일 처리율, 일별·분류별·팀별·처리자별, **반복 민원**(같은 장소·분류 2회 이상), 월간 처리 내역 → **인쇄/PDF, 엑셀 다운로드**
- **검색**: "2층 화장실" 처럼 장소·내용·처리 댓글까지 검색, 기간 필터, 언제 누가 완료했는지 표시
- **알림**: 내 담당(또는 내 팀) 지정 시 토스트+브라우저 알림+진동, 채팅 미확인 배지

## 백엔드 (Supabase 프로젝트 `minwon`)
기존 시스템 테이블(complaints/events/staff…)은 건드리지 않고 아래를 새로 추가했습니다.

| 종류 | 이름 | 비고 |
|---|---|---|
| 테이블 | `public.mw_issues` | 민원 (logs/photos/assignee 는 jsonb) |
| 테이블 | `public.mw_chat` | 채팅 메시지 |
| 스토리지 | `mw-photos` (공개 읽기, 5MB, 이미지만) | 사진은 기기에서 1000px JPEG로 압축 후 업로드 |
| 실시간 | `supabase_realtime` 발행에 두 테이블 추가 | WebSocket이 막힌 망에서는 8초 폴링으로 자동 전환 |

RLS 정책은 `anon` 키로 읽기/쓰기를 허용합니다(앱에 로그인 비밀번호가 없는 단순 구조). 외부 노출이 걱정되면 사업소별 입장 코드나 Supabase 익명 로그인으로 조이면 됩니다.

오프라인/서버 오류 시에는 기기(localStorage)에 저장되고 대기열에 쌓였다가 재연결 때 자동 전송됩니다.
