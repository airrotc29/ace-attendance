# 민원 처리 공유 시스템 (`minwon/index.html`)

관리사무소 직원 **누구나** 민원을 올리고, 담당을 정하고, 처리 결과를 사진과 함께 보고하며, 모두가 실시간으로 공유하는 단일 HTML 앱입니다.
(소장님 통화 요구사항 반영: 한 사람이 지시하지 않아도 서로 과업을 주고받고, 카톡처럼 편하되 **통계·검색**이 남도록)

## 주요 기능
- **입장**: 사업소 선택 → 이름 선택 (출퇴근 시스템과 동일 직원 명단, 직급으로 팀 자동 분류: 사무실/시설팀/미화팀/보안팀/주차)
- **민원 접수**: 한 줄 내용·장소·분류·접수경로(전화/방문/순찰 발견…)·사진·담당(미지정/팀/직원/내가 처리)·긴급
- **처리 흐름**: 내가 처리 → 진행 보고(사진) → 완료 처리(완료 사진) → 재발 시 다시 열기. 모든 과정이 타임라인으로 남음
- **채팅**: 전체 단톡방. 작업 안내/수돗물 잠금/점검 등 빠른 문구, 사진 첨부. 접수·담당지정·완료는 자동으로 채팅에 올라오고 눌러서 민원으로 이동
- **통계**: 월별 접수/완료/처리율/평균 처리시간/당일 처리율, 일별·분류별·팀별·처리자별, **반복 민원**(같은 장소·분류 2회 이상), 월간 처리 내역 → **인쇄/PDF, 엑셀 다운로드**
- **검색**: "2층 화장실" 처럼 장소·내용·처리 댓글까지 검색, 기간 필터, 언제 누가 완료했는지 표시
- **알림**: 내 담당(또는 내 팀) 지정 시 토스트+브라우저 알림+진동, 채팅 미확인 배지

## 접근 구조 (사업소별 격리)
- **본사 관리자**: 사업소 코드 `HQ` + 본사 비밀번호로 로그인하면 사업소를 만들고, 사업소별 직원 명단을 입력(붙여넣기 또는 한 명씩)하며, 사업소 비밀번호를 바꾸거나 사업소를 삭제합니다.
- **사업소 직원**: 사업소 코드 + 사업소 비밀번호로 로그인한 뒤 본인 이름을 고릅니다. 같은 사업소의 민원·채팅·명단만 보입니다.
- 테이블은 익명 키로 직접 읽거나 쓸 수 없습니다. 모든 접근은 `mw_*` 함수를 거치며, 함수 안에서 사업소 코드와 비밀번호(bcrypt 해시)를 확인하고 본인 사업소 데이터만 다룹니다.
- 기기에는 로그인 정보가 저장되어 자동 입장됩니다. 공용 PC라면 나가기를 누르세요.

## 소장 직원 관리
- 본사 관리자가 사업소마다 **소장 비밀번호**(4자 이상)를 정합니다. 사업소를 만들 때 넣거나, 목록의 "소장 비번" 버튼으로 나중에 정합니다.
- 소장 직급으로 입장하면 상단에 **직원** 버튼이 보입니다. 소장 비밀번호를 넣으면 자기 사업소 직원을 추가·삭제할 수 있습니다.
- 서버는 사업소 비밀번호와 별도로 소장 비밀번호를 확인합니다. 소장 비밀번호는 기기에 저장하지 않고 접속 중에만 기억합니다.

## 관리단 월간보고서
- 통계 탭의 **관리단 월간보고서 만들기**에서 수신처, 보고일, 작성자, 개선 건의, 특이사항을 넣으면 A4 공문 형식의 보고서가 새 창에 열립니다.
- 구성: 결재란(담당·소장), 총괄 현황(전월 대비), 분류별 현황, 접수 경로, 담당 팀별 배정, 처리 완료 내역, 미완료 민원 및 향후 조치, 반복 민원 및 개선 건의, 처리 사진 대장(선택), 특이사항, 소장 명의 맺음말.
- 인쇄하거나 PDF로 저장해 제출합니다. 입력한 수신처와 문구는 기기에 저장되어 다음 달에 다시 채워집니다.

## 앱으로 설치 (홈 화면 · 바탕화면 아이콘)
- 로그인 화면의 **앱으로 설치하기** 버튼, 입장 후 상단 바의 다운로드 아이콘으로 설치합니다.
- 안드로이드 · PC 크롬 · 엣지는 바로 설치 창이 뜨고, 아이폰은 사파리의 "공유 → 홈 화면에 추가" 안내가 나옵니다.
- 설치된 상태로 열면 버튼이 숨겨집니다.
- 구성: `manifest.webmanifest`(앱 이름 · 아이콘 · 색), `sw.js`(앱 파일은 네트워크 우선, 끊기면 저장본 사용 · 서버 데이터는 저장하지 않음), `icons/`(192 · 512 · 마스커블 · 애플 터치 · 파비콘).

## 백엔드 (Supabase 프로젝트 `minwon`)
| 종류 | 이름 | 비고 |
|---|---|---|
| 테이블 | `mw_offices`, `mw_employees` | 사업소(코드·비밀번호·소장 비밀번호 해시), 직원 명단 |
| 테이블 | `mw_issues`, `mw_chat` | 민원, 채팅 (직접 접근 차단, 함수로만 접근) |
| 함수 | `mw_login`, `mw_issues_list`, `mw_issue_save`, `mw_chat_save` 등 | 사업소 인증 후 본인 데이터만 처리 |
| 스토리지 | `mw-photos` (공개 URL, 목록 조회 불가) | 사진은 기기에서 1000px JPEG로 압축 |

동기화는 6초마다 서버를 확인하는 방식입니다. 오프라인이나 서버 오류 시 기기에 저장했다가 연결되면 자동으로 올립니다.
